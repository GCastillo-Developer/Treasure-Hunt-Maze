Treasure Hunt: Deep Q-Learning Pirate Agent
This project implements a Deep Q-Learning (DQN) reinforcement learning model where an AI-controlled pirate navigates a grid-based maze (TreasureMaze.py) to find hidden treasure while maximizing rewards and avoiding obstacles.

Key Features
Intelligent Agent: Uses a neural network to approximate Q-values and determine the optimal navigation sequence.

Experience Replay: Leverages a custom experience class (GameExperience.py) to store and learn from past episodes.

Exploration vs. Exploitation: Configurable epsilon-greedy strategy balancing random exploration with optimal path exploitation.

Optimized Training: Tuned epoch cycles designed to achieve a reliable 100% win rate.
